# 农产品电商仓配管理系统 — 项目介绍

## 一、项目背景

某生鲜电商平台需要开发一套农产品仓配管理系统，用于管理仓库内农产品的**入库、存储、拣货、出库、补货、配送**等全链路环节。由于农产品具有**易腐、保质期短、季节性强**等特点，系统需支持：

- **先进先出（FIFO）**策略，避免商品过期损耗
- **保质期预警**，及时提醒临期商品
- **动态拣货路径规划**，提升仓库作业效率
- **与订单系统对接**，实现高效履约

## 三、系统功能模块

### 功能总览

```
农产品电商仓配管理系统
├── 1. 仪表盘          数据总览、快速入口、策略切换
├── 2. 商品管理        农产品信息CRUD、分类筛选、图片上传(OSS)
├── 3. 库存管理        库存台账、批次追溯、临期/低库存预警
├── 4. 入库管理        入库单 → 质检 → 上架（储存条件匹配货位）
├── 5. 出库拣货        出库单 → 移入拣货区 → 分配拣货员 → 拣货确认 → 扣库存
├── 6. 订单管理        客户订单 → 库存锁定 → 生成出库单 → 拣货任务 → 物流单打印
├── 7. 补货管理        低库存检测 → 补货任务 → 确认补货
├── 8. 报表分析        库存周转统计、操作日志审计
└── 9. 系统管理        用户权限、系统配置、操作日志
```

### 1. 仪表盘

- 实时统计卡片：商品种类数、库存批次数、临期预警数、活跃订单数、待补货数
- 拣货策略一键切换：FIFO / FEFO / 分类优先
- 快速操作入口：创建入库单、出库单、订单

### 2. 商品管理

- 农产品信息维护：名称、分类（叶菜/根茎/水果/冷链品/粮油）、保质期、存储条件（常温/冷藏/冷冻）、单位
- 商品图片上传：对接阿里云 OSS，保存时自动上传并在列表中展示缩略图
- 选择分类后即时筛选该分类商品
- 删除商品前检查所有关联数据（库存/入库单/出库单/拣货任务/订单），页面内弹窗确认

### 3. 库存管理

- 库存台账：批次号、当前数量、货位编号、生产日期、到期日期
- 保质期预警：到期前 7 天自动标记"临期"状态
- 低库存预警：按商品汇总库存总量 ≤ 50 时触发预警
- 批次追溯：关联商品信息、货位信息

### 4. 入库管理

- 创建入库单：选择商品 → 显示储存条件 → 自动查询匹配温区的空闲货位供选择 → 填写批次/数量
- 储存条件与货位匹配：常温→常温区 / 冷藏→冷藏区 / 冷冻→冷冻区
- 质检环节：合格 → 上架；不合格 → 取消入库
- 上架操作：直接使用入库时选定的货位，自动创建库存记录
- 撤销功能：误操作可撤销最近一次入库（命令模式）

### 5. 出库拣货

- 创建出库单：选择商品 → 选择拣货策略 → 系统自动规划拣货路径（货架号 → 拣货区 → 出口）
- 移入拣货区：货物从货架移至拣货区，路径追加"拣货区"
- 分配拣货员：从拣货员和仓管员角色中选取
- 拣货确认：仅管理员或被分配的拣货员/仓管员可操作 → 扣减库存 → 路径追加"出口"
- 拣货策略：FIFO（先入先出）/ FEFO（最短保质期优先）/ 分类优先
- 支持跨批次拣货：总量足够时自动从多个批次凑齐出库数量
- 撤销功能：误操作可撤销最近一次出库

### 6. 订单管理

- 创建客户订单：选择商品 → 填写客户信息/配送地址
- 订单处理：库存锁定 → 生成出库单 → 生成拣货任务 → 打印物流单
- 订单处理后的出库单走正常的出库拣货流程
- 拣货确认后自动将订单标记为"已完成"，同时释放锁定的库存
- 取消订单时自动释放锁定的库存

### 7. 补货管理

- 补货触发条件：低库存 / 商品过期 / 报损
- 创建补货任务 → 确认补货 → 库存自动增加
- 记录补货原因和操作人

### 8. 报表分析

- 库存周转报表：各商品入库总量、出库总量、当前库存、周转率
- 操作日志审计：记录所有关键操作，支持分页查看
- 操作人、操作时间、操作详情完整可追溯

### 9. 系统管理

- 用户管理：三种角色（管理员 / 仓管员 / 拣货员）
- 权限控制（代理模式）：不同角色可执行的操作不同
- 系统配置（单例模式）：仓库名称、预警阈值等参数管理
- 系统日志：内存中实时操作日志查看

## 四、核心业务流程

### 入库流程

```
创建入库单 → 选商品(显示储存条件) → 选货位(按温区匹配) → 填数量/批次
                                                              ↓
                                                         质检 → 合格 → 上架 → 创建库存 → 通知观察者
                                                              ↓
                                                         不合格 → 取消入库

                    支持撤销 → 回滚上架 + 删除库存 (命令模式)
```

### 出库拣货流程

```
创建出库单 → 选拣货策略 → 生成拣货路径(货架号)
                              ↓
                        移入拣货区(路径 + "拣货区")
                              ↓
                       分配拣货员(拣货员/仓管员中选择)
                              ↓
                   拣货确认(扣库存，路径 + "出口"，跨批次支持)
                              ↓
                 关联客户订单自动完成 → 锁定库存自动释放

                    支持撤销 → 回滚出库 + 恢复库存 (命令模式)
```

### 订单处理流程

```
客户下单(待处理)
     │
     ├─ 处理订单：库存锁定 → 生成出库单 + 拣货任务 → 打印物流单
     │           订单状态 → "已锁定库存"
     │
     ├─ 出库单走正常出库拣货流程：
     │   待拣货 → 移入拣货区 → 分配拣货员 → 拣货确认
     │
     └─ 拣货确认后自动触发：
         出库单 → 已完成
         客户订单 → 已完成
         锁定库存 → 恢复为正常
```

### 补货流程

```
系统检测低库存 → 创建补货任务 → 确认补货(库存增加) → 任务完成
                      │
                      └── 记录原因: 低库存/过期/报损
```

### 设备状态流转（状态模式）

```
           startWork()           stopWork()
  空闲 ──────────────→ 作业中 ──────────────→ 空闲
   │                     │
   │ reportFault()       │ reportFault()
   ↓                     ↓
  故障 ←──────────────────┘
   │ finishCharge()
   ↓
  空闲

  充电中 ──finishCharge()──→ 空闲

  防止非法操作: 故障状态下任何操作都不会改变状态
```

## 八、设计模式应用总结

系统共应用 **8 种 GoF 设计模式**，覆盖全部核心业务场景：

| 模式 | 应用场景 | 核心价值 |
|------|----------|----------|
| 工厂方法 | 创建各类仓库单据 | 统一单据生成，便于扩展新类型 |
| 策略 | 拣货策略/存储策略切换 | 运行时动态切换算法，无需重启 |
| 命令 | 操作封装与撤销 | 支持误操作回滚，完整操作审计 |
| 状态 | PDA设备状态管理 | 防止非法状态转换 |
| 观察者 | 库存变化自动通知 | 解耦库存中心与各订阅模块 |
| 单例 | 配置/日志管理器 | 全局唯一实例，统一管理 |
| 代理 | 操作权限控制 | 权限校验与业务逻辑分离 |
| 责任链 | 订单处理流程 | 步骤化处理：锁定→出库单→拣货任务→物流单 |

> 详细设计模式说明见：[DESIGN_PATTERNS.md](./DESIGN_PATTERNS.md)

## 九、启动与使用

### 环境要求

- JDK 17+
- MySQL 8.0+
- Maven 3.x

### 启动步骤

```bash
# 1. 初始化数据库
mysql -u root -p1234 --default-character-set=utf8mb4 < sql/schema.sql

# 2. 导入种子数据（可选）
mysql -u root -p1234 --default-character-set=utf8mb4 < sql/seed-data.sql

# 3. 启动后端服务
mvn spring-boot:run

# 4. 浏览器访问
http://localhost:8080
```
