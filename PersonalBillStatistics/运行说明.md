# pocket-budget 项目运行说明

本文档用于说明 `PersonalBillStatistics` 项目的本地运行方式。项目采用前后端分离结构：

- 后端：Java 17 + Spring MVC + MyBatis + MySQL，打包为 `StatsDashboard.war`
- 前端：Vue 3 + Vite，项目名为 `pocket-budget`
- 数据库：MySQL，默认库名 `db_bill`

## 1. 环境要求

请先确认本机已安装以下环境：

| 环境 | 建议版本 | 说明 |
| --- | --- | --- |
| JDK | 17 或以上 | 后端编译运行 |
| Maven | 3.6 或以上 | 后端依赖下载和打包 |
| MySQL | 8.0 或以上 | 项目数据库 |
| Node.js | 18 或以上 | 前端依赖和 Vite 开发服务 |
| Tomcat | 9.x | 部署 Spring MVC 后端 WAR 包 |

## 2. 数据库初始化

先启动 MySQL，然后执行下面的 SQL 创建数据库和表。

```sql
CREATE DATABASE IF NOT EXISTS db_bill
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_unicode_ci;

USE db_bill;

CREATE TABLE IF NOT EXISTS user (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    email VARCHAR(100)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS category (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    type ENUM('income','expense') NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS bill (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    amount DECIMAL(12,2) NOT NULL,
    type ENUM('income','expense') NOT NULL,
    category_id INT NOT NULL,
    date DATE NOT NULL,
    remark VARCHAR(255),
    FOREIGN KEY (user_id) REFERENCES user(id),
    FOREIGN KEY (category_id) REFERENCES category(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

账单新增时需要选择分类，如果 `category` 表为空，可以先执行以下初始化分类：

```sql
USE db_bill;

INSERT INTO category (name, type) VALUES
('工资', 'income'),
('奖金', 'income'),
('兼职', 'income'),
('餐饮', 'expense'),
('购物', 'expense'),
('交通', 'expense'),
('住房', 'expense'),
('娱乐', 'expense'),
('医疗', 'expense'),
('学习', 'expense');
```

用户密码由后端使用 BCrypt 加密保存，建议不要手动向 `user` 表插入明文密码。启动项目后，直接在前端注册账号即可。

## 3. 检查数据库连接配置

后端数据库配置文件位置：

```text
src/main/resources/application.properties
```

当前默认配置为：

```properties
db.url=jdbc:mysql://localhost:3306/db_bill?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
db.username=root
db.password=1234
db.driver=com.mysql.cj.jdbc.Driver
```

如果本机 MySQL 用户名或密码不同，请修改 `db.username` 和 `db.password`。

## 4. 启动后端

### 方式一：使用 IDEA + Tomcat

1. 用 IntelliJ IDEA 打开项目根目录：

   ```text
   D:\javaweb\workspace\PersonalBillStatistics
   ```

2. 等待 Maven 依赖加载完成。

3. 配置 Tomcat：

   - `Run` -> `Edit Configurations`
   - 添加 `Tomcat Server` -> `Local`
   - 部署项目生成的 WAR 或 exploded artifact
   - 建议将 Application context 设置为 `/`

4. 启动 Tomcat 后，后端地址应为：

   ```text
   http://localhost:8080
   ```

前端 Vite 代理默认把 `/api` 转发到 `http://localhost:8080`，所以后端建议部署在根路径 `/`。如果后端部署路径是 `/StatsDashboard`，需要同步调整 `frontend/vite.config.js` 的代理地址。

### 方式二：命令行打包后部署

在项目根目录执行：

```bash
mvn.cmd clean package
```

打包成功后会生成：

```text
target/StatsDashboard.war
```

将该 WAR 包部署到 Tomcat。如果希望前端无需改代理配置，建议部署为 Tomcat 根应用，也就是放置为：

```text
Tomcat/webapps/ROOT.war
```

或在 IDEA/SmartTomcat 中将 context path 设置为 `/`。

## 5. 启动前端

进入前端目录：

```bash
cd D:\javaweb\workspace\PersonalBillStatistics\frontend
```

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

默认访问地址：

```text
http://localhost:5173
```

前端接口请求配置如下：

- 前端请求基础路径：`/api`
- Vite 代理目标：`http://localhost:8080`
- 配置文件：`frontend/vite.config.js`

## 6. 运行顺序

推荐按以下顺序启动：

1. 启动 MySQL
2. 执行数据库建表 SQL
3. 确认 `application.properties` 数据库账号密码正确
4. 启动后端 Tomcat，确保后端在 `http://localhost:8080`
5. 启动前端 Vite，访问 `http://localhost:5173`
6. 在前端注册账号并登录
7. 添加账单，查看统计图表

## 7. 常用接口

后端接口路径保持在 `/api` 下：

| 方法 | 路径 | 说明 | 是否需要登录 |
| --- | --- | --- | --- |
| POST | `/api/register` | 用户注册 | 否 |
| POST | `/api/login` | 用户登录 | 否 |
| GET | `/api/logout` | 退出登录 | 否 |
| GET | `/api/user/current` | 获取当前登录用户 | 是 |
| GET | `/api/categories` | 查询分类 | 否 |
| GET | `/api/bills` | 分页查询账单 | 是 |
| POST | `/api/bills` | 新增账单 | 是 |
| PUT | `/api/bills/{id}` | 修改账单 | 是 |
| DELETE | `/api/bills/{id}` | 删除账单 | 是 |
| GET | `/api/statistics/category` | 分类统计 | 是 |
| GET | `/api/statistics/monthly` | 月度统计 | 是 |
| GET | `/api/statistics/monthly-compare` | 月度收支对比 | 是 |

登录状态使用 Session 保存，前端 Axios 已开启 `withCredentials: true`，后端也允许 `http://localhost:5173` 跨域携带凭据。

## 8. 常见问题

### 数据库连接失败

检查以下内容：

- MySQL 是否已启动
- 是否已创建 `db_bill`
- `application.properties` 中的用户名和密码是否正确
- MySQL 端口是否为 `3306`

### 前端提示无法连接服务器

检查以下内容：

- 后端 Tomcat 是否已启动
- 后端是否运行在 `http://localhost:8080`
- `frontend/vite.config.js` 的代理目标是否正确
- 后端如果不是根路径 `/`，需要修改代理目标或重新部署为根应用

### 新增账单时没有分类

说明 `category` 表没有数据。请执行本文档第 2 节中的分类初始化 SQL。

### 登录失败或用户不存在

请先在前端注册账号。不要直接向 `user` 表插入明文密码，因为后端登录校验使用 BCrypt 加密密码。

### Maven 依赖下载失败

检查网络连接，或配置 Maven 镜像源。例如在 Maven `settings.xml` 中配置国内镜像。
