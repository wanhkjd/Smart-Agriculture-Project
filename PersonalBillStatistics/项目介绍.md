# 个人账单统计系统 - 项目运行说明

## 📋 项目简介

个人账单统计系统是一个基于 Vue 3 + Spring MVC 的前后端分离应用，用于记录和管理个人收支账单，并提供数据统计分析功能。

### 技术栈

**后端：**
- Java 17
- Spring Framework 5.3.31 (Spring MVC)
- MyBatis 3.5.14
- MySQL 8.0
- HikariCP 连接池
- Tomcat 9
- Maven

**前端：**
- Vue 3.5
- Vite 8.0
- Vue Router 4.6
- Axios 1.16
- ECharts 6.1

## 🚀 快速启动

### 第一步：数据库准备

1. **启动 MySQL 服务**

2. **执行数据库初始化脚本**

   打开 MySQL 命令行或图形化工具（如 Navicat、MySQL Workbench），执行以下命令：

   ```bash
   # 方式一：使用 mysql 命令行
   mysql -u root -p < src/main/resources/schema.sql
   
   # 方式二：在 MySQL 客户端中直接执行 SQL 文件内容
   ```

   该脚本会自动：
   - 创建数据库 `personal_bill`
   - 创建三张表：`user`、`category`、`bill`
   - 插入默认分类数据（餐饮、购物、交通等）
   - 插入测试用户（用户名：jack，密码：1234）
   - 生成 2025年6月 - 2026年5月的示例账单数据

3. **修改数据库配置**

   编辑 `src/main/resources/application.properties` 文件，根据您的 MySQL 配置修改：

   ```properties
   db.url=jdbc:mysql://localhost:3306/personal_bill?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
   db.username=root          # 修改为您的 MySQL 用户名
   db.password=1234          # 修改为您的 MySQL 密码
   db.driver=com.mysql.cj.jdbc.Driver
   ```

---

### 第二步：启动后端服务

#### 方式一：使用 IntelliJ IDEA（推荐）

1. 用 IntelliJ IDEA 打开项目根目录 `PersonalBillStatistics`
2. 等待 Maven 依赖自动下载完成
3. 配置 Tomcat 服务器：
   - 点击菜单栏 `Run` → `Edit Configurations`
   - 点击 `+` → 选择 `Tomcat Server` → `Local`
   - 设置 Tomcat 安装路径（如：`D:\javaweb\apache-tomcat-9.0.108`）
   - 在 `Deployment` 标签页添加 Artifact：`PersonalBillStatistics:war exploded`
   - 设置 Application context 为 `/`
4. 点击运行按钮启动服务
5. 后端服务将在 `http://localhost:8080` 启动

#### 方式二：使用 Maven 命令

```bash
# 在项目根目录下执行
mvn clean package

# 将生成的 war 包部署到 Tomcat
# 或将 target/PersonalBillStatistics-1.0-SNAPSHOT.war 复制到 Tomcat 的 webapps 目录
```

---

### 第三步：启动前端服务

1. **进入前端目录**

   ```bash
   cd frontend
   ```

2. **安装依赖**

   ```bash
   npm install
   ```

3. **启动开发服务器**

   ```bash
   npm run dev
   ```

4. 前端服务将在 `http://localhost:5173` 启动，浏览器会自动打开

## 🔧 常见问题

### 1. 端口被占用

**后端端口 8080 被占用：**
- 修改 Tomcat 配置文件的端口号（`conf/server.xml`）
- 或关闭占用 8080 端口的进程

**前端端口 5173 被占用：**
- Vite 会自动尝试其他端口（5174、5175...）
- 或在 `vite.config.js` 中手动修改端口号

### 2. 数据库连接失败

检查以下配置：
- MySQL 服务是否已启动
- `application.properties` 中的用户名和密码是否正确
- 数据库 `personal_bill` 是否已创建
- MySQL 版本是否为 8.0+（需要使用 `com.mysql.cj.jdbc.Driver`）

### 3. 前端无法连接后端

- 确认后端服务已在 `http://localhost:8080` 正常运行
- 检查 `frontend/vite.config.js` 中的代理配置：
  ```javascript
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // 确保端口正确
      changeOrigin: true
    }
  }
  ```
- 检查浏览器控制台是否有 CORS 错误

### 4. Maven 依赖下载失败

- 检查网络连接
- 配置国内 Maven 镜像（阿里云）：
  
  在 `~/.m2/settings.xml` 中添加：
  ```xml
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
  ```

### 5. 日志过多

如果启动时看到大量 DEBUG 日志，检查 `src/main/resources/logback.xml` 文件是否存在且配置正确。

## 🎯 主要功能

1. **用户管理**
   - 用户注册
   - 用户登录/登出
   - Session 认证

2. **账单管理**
   - 新增账单（收入/支出）
   - 查询账单列表
   - 删除账单
   - 按日期、类型筛选

   - 查看收支分类

4. **统计分析**
   - 月度收支统计
   - 分类占比分析
   - 月度对比图表
   - ECharts 可视化展示

## 📝 API 接口说明

后端提供 RESTful API，所有接口前缀为 `/api`：

| 接口 | 方法 | 说明 | 需要认证 |
|------|------|------|---------|
| `/api/register` | POST | 用户注册 | ❌ |
| `/api/login` | POST | 用户登录 | ❌ |
| `/api/logout` | POST | 用户登出 | ❌ |
| `/api/categories` | GET | 获取分类列表 | ❌ |
| `/api/bills` | GET | 获取账单列表 | ✅ |
| `/api/bills` | POST | 新增账单 | ✅ |
| `/api/bills/{id}` | DELETE | 删除账单 | ✅ |
| `/api/statistics/monthly` | GET | 月度统计 | ✅ |
| `/api/statistics/category` | GET | 分类统计 | ✅ |
| `/api/statistics/compare` | GET | 月度对比 | ✅ |

---

## 🔐 认证机制

- 使用 Session 进行用户认证
- 登录成功后将用户名存入 Session
- `AuthInterceptor` 拦截器保护需要认证的接口
- 未认证用户访问受保护接口会返回 401 状态码
- 前端检测到 401 会自动跳转到登录页
